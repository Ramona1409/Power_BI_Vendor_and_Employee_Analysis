# NYC Yellow Taxi Analysis

## Project Overview

This project uses Power BI to explore New York City Yellow Taxi trip data for May and June 2020. The report is designed to support the analysis of taxi trip patterns using trip records and taxi zone lookup data.

## Business Objectives

Explore taxi trip patterns across the selected months.

Analyze trip activity by pickup and drop-off zones.

Compare taxi activity between May and June 2020.

Use data visualization to identify patterns and trends in taxi trips.

## Tools & Technologies

**Power BI Desktop** – report development and data visualization

**Power Query** – data preparation and transformation

**CSV datasets** – taxi trip records and zone lookup data

## Dataset

The project uses the following data sources:

Yellow Taxi trip data for May 2020.

Yellow Taxi trip data for June 2020.

Taxi zone lookup data for identifying pickup and drop-off locations.

## Key Areas of Analysis

Monthly taxi trip activity.

Pickup and drop-off zone patterns.

Comparisons between the selected months.

Visual exploration of trip data.

## Conclusion

This project demonstrates the use of Power BI for data preparation, visualization, and exploratory analysis of transportation data.
